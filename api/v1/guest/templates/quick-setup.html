Quick Setup

LogArbor is designed to get you logging in under 5 minutes. Follow the steps below to start sending logs immediately.

1. Login/Signup

Create a brand new account and then login or you can just use your github account to login if you want to.

2. Create a Service

Go to Services -> + New Service.

When filling out the new service info the "Alert Level" is the log level you want your service to recognize as logs come in and send an alert if the log's level is or worse than your service's alert level.

Alert Level Example

Here are all the supported log levels: ["debug", "info", "warning", "error", "critical"]. For example, you service's alert level is "warning", if your application sends a log to that service with level of warning or anything beyond it like: "error" or "critical" that an alert is going to be triggered and email is going to be sent to you as well. You can check all alerts by going to Alerts.

Those alerts also effect your error rate graph in Dashboard because it consists of the logs that trigger alerts.

3. Send logs


# Install LogArbor Client
pip install log-arbor

# Import the client(also don't forget to put your service_id and access_token you copied earlier in the env file and import them using os)
from log-arbor.utils import log

log(service_id, "info", "this is a log with info level", access_token)

Now, when you run your app or a script you can check your incoming logs in the Logs page in real-time!

You can also check the metrics about the logs in the Dashboard page also in real-time. If you don't see your logs that means your log function was set incorrectly, so check the fourth step out.

4. Troubleshooting

If you don't see your logs in Logs page you should check your inbox for an alert explaining what went wrong.

Important: the alerts that explain what went wrong while sending a log will not be in the Alerts page, they are going to be only in your inbox. Alerts page is designed to visualize the alerts that are caused by unwanted logs like error logs.
