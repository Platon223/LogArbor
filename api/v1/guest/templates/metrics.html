Metrics

All of the metrics about your logs are going to be in the Dashboard page.

There's 3 graphs that are on that page.

1. Logs per day graph, is a line graph that shows the amount of logs each service has per day.

2. Log speed graph, is a bar graph that shows the speed of logs incoming to each service.

3. Error rate graph, is a donut graph that shows the rate of logs that caused alerts in a service.
