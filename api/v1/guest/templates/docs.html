Introduction

v1.0.0

LogArbor is a modern log aggregation and monitoring platform designed for developers who want real-time insight into their logs without complexity.

You can also check how LogArbor works in github repo(you will have to scroll down in the README file in order to see the diagram): LogArbor Github Repo

Why LogArbor?

  • Terminal-style real-time log streaming
  • Simple Setup
  • Service-level isolation
  • Developer-first UX

Quick Example


# Install CLI
pip install logarbor

# Initialize a service

Services -> + New Service

# Send a log
from log_arbor.utils import log

log(service_id, level, message, access_token)

Hint

You can get your access_token variable you just saw in the quick example by going Settings -> API Keys and copy the token. Then use it as the forth parameter in the log function.
