Usage

Once installed, use Larb with the following commands:

# Initialize Larb configuration, you can get your api key in the settings.
larb init <your_api_key>

# Create a service 
larb add --name <Name> --level <AlertLevels: [debug, info, warning, error, critical]

# View logs for a specific service
larb get --id <service-id>

# Tail logs in real-time
larb tail logs <service-id>

# Chat with Logby (AI Assistant)
larb chat

# List all services
larb all

# Get all of the alerts
larb alerts

# View metrics, types are: [count, speed, error]
larb metrics --type <metric-type> 

# Get the version
larb version
