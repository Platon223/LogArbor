What is LogArbor?

LogArbor collects, structures, and visualizes logs from all your services in real time. No clutter. No noise. Just clear, searchable insight into what your systems are doing.

Why LogArbor?

⚡ Real-Time Logs

Stream logs instantly with terminal-style clarity across all your services.

🔒 Secure by Design

JWT auth, service tokens, and role-based access — built in from day one.

🧩 Developer First

Simple API, clean UI, no unnecessary complexity. Just logs.

Quick Setup

Step 1 — Install
# Install the LogArbor client via pip $ pip install log-arbor
Step 2 — Create a Service
# In the Dashboard → Sidebar → Services → New Service # Fill in the fields: Url = "https://your-application.com" Alert Level = "error" # the log level that triggers an alert # Learn more: /support/services
Step 3 — Send Logs
from log_arbor.utils import log # log(service_id, level, message, access_token) log("your_service_id", "info", "Server started on port 8080", "your_access_token") log("your_service_id", "warn", "Memory usage above 80%", "your_access_token") log("your_service_id", "error", "Unhandled exception in /api/users", "your_access_token")
Step 4 — View Logs
# Go to Services page and find your service. Then watch your logs in real time. # Find your service and watch logs stream in real time ✓
